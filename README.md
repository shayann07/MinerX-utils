## 📖 Overview

A small web tool for MinerX admins to look up per-level team deposits for any user, streaming results into the page live as they're computed on the backend.

---

## ✨ Key Features

- **Admin Tool**: Built-in support and optimized flows for admin tool.
- **Firebase**: Built-in support and optimized flows for firebase.
- **Html**: Built-in support and optimized flows for html.
- **Javascript**: Built-in support and optimized flows for javascript.
- **Lookup Tool**: Built-in support and optimized flows for lookup tool.

## 🚀 Getting Started

### Prerequisites
- Node.js / Modern Web Browser

### Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/shayann07/MinerX-utils.git
   cd MinerX-utils
   ```
2. Open in browser or local server:
   ```bash
   npx serve .
   ```
